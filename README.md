# IEGO Edit

Editor di salvataggi per **Inazuma Eleven GO** (3DS) con la patch Luma "IEGO Deluxe".
Progetto amatoriale, non affiliato né approvato da Level-5 o Nintendo.

## Installazione dal 3DS (consigliata)

1. Apri **FBI** → **Remote Install** → **Scan QR Code**
2. Inquadra questo QR:

![QR](https://github.com/leo5295/iego-edit-releases/releases/download/latest/qr.png)

3. Scegli **Download and install**.

L'indirizzo non cambia mai: il QR scarica sempre l'ultima versione.

## Altri file

Nella sezione **Releases** trovi anche `iegoedit.cia` e `iegoedit.3dsx` (per il menu Homebrew).

## Aggiornamenti

Dentro l'app, la voce **Aggiorna** controlla se c'è una versione più recente.

## Avvertenza

Fai sempre una copia del salvataggio prima di modificarlo (l'app crea comunque un backup).
Uso a proprio rischio.
